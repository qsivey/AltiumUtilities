; Shared color presets for SchematicStyleChanger and LibraryStyleChanger
; Shared file: Libraries\StylePresets.txt
; Copy one complete [section], give it a unique name, and edit its colors.
; Each preset must contain all twelve roles, in any order.
; Colors: #RRGGBB (red, green, blue), NOT Altium's internal BGR format.
; Example: #FF0000 = red, #00FF00 = green, #0000FF = blue.
; Whole lines beginning with ; are comments. Do not append comments to values.
; Save as UTF-8 with BOM if using non-ASCII preset names.
; Open the preset list to reload this file; Apply preset changes the swatches.
; Run applies the swatches to selected SchDoc or SchLib files.
; LibraryStyleChanger uses BodyOutline, BodyFill, Graphics, Parameters, PinText, Images.
; The other six roles apply only to schematics; keep all twelve roles in each preset.
; PNG mode and Body fill Enable / Transparent are selected separately.
;
; BodyOutline = rectangle and ellipse outlines; also Polygon outlines in libraries
; BodyFill    = component Rectangle fills; also Polygon fills in libraries
; Graphics    = graphic lines, curves and arcs; also polygons in schematics
; Parameters  = parameters and component designators
; PinText     = pins, pin labels, ordinary text and 20 mil arcs
; Images      = PNG pixel color, used only in Recolor mode
; Wires       = electrical wires and manual junctions
; PortBorder  = port outline
; PortFill    = port interior fill
; PortFont    = port text
; Other       = remaining schematic primitives
; SheetColor  = sheet background (excluded from the common-accent button)
;
; 21 palettes use a white sheet; 16 multicolor palettes use tinted sheets.
; Classic: symbol colors from ClassicStyleSymbols; Wire/Port colors from qsiveyGlobalPresetsClassic.DXPPrf.
; Extended preserves the previous Classic preset unchanged.
