SchematicStyleChanger v1.8.5

Запуск
1. Открой SchematicStyleChanger.PrjScr в Altium.
2. Запусти RunSchematicStyleChanger.
3. Выбери папку со схемами и отметь нужные SchDoc. Подпапки не сканируются.
   По умолчанию выбрана папка текущего листа, иначе папка активного проекта.
4. Выбери цвета. One color for all accents (except sheet) задаёт один цвет
   всем 11 акцентам. Фон листа Sheet Color выбирается отдельно.
   Enable рядом с Body fill включает заливку Rectangle внутри компонентов;
   по умолчанию включён. Transparent рядом с ним по умолчанию выключен.
5. В списке Junctions выбери Leave unchanged, Manual junctions или Global color.
   Manual и Global используют цвет Wires; Global действует во всех схемах Altium.
6. В PNG images выбери Leave unchanged, Recolor или Return to original image.
7. При необходимости включи Create defaults.
8. Run создаёт выбранные файлы Defaults и изменяет выбранные SchDoc на месте.

Пресеты
Внизу группы цветов выбери пресет в списке и нажми Apply preset.
Пресет меняет все 12 цветовых образцов, включая фон листа. К схемам цвета применяются кнопкой Run.
Режимы PNG images и Junctions, флажки Body fill / Enable, Transparent и Create defaults
сохраняют своё состояние при выборе пресета.

Название темы на схеме
При Run на каждом обработанном листе создаётся текст Theme: <название темы>.
Координаты: X=400 mil, Y=400 mil. Шрифт: Times New Roman, 14 pt, обычный.
Текст горизонтальный, точка привязки — нижний левый угол.
Цвет берётся из Pins / text / 20 mil arcs.
Название запоминается при нажатии Apply preset. Простого выбора в списке
недостаточно: он не меняет ни цвета, ни название применённой темы.
Если пресет не применялся или затем цвет изменён вручную, используется Theme: Custom.
Повторный Run обновляет существующую надпись Theme: в точке (400, 400 mil),
не добавляя ещё одну. Текст внутри компонентов и надписи в других местах не затрагиваются.
Подпись добавляется только на листы SchDoc, а не в создаваемые Defaults.

Файл StylePresets.txt находится в общей папке Libraries в корне репозитория.
Скрипт ищет его по относительному пути ..\..\..\Libraries\StylePresets.txt
от папки SchematicStyleChanger, поэтому перемещение всего репозитория допустимо.
В файле 37 пресетов: 21 с белым фоном и 16 разноцветных
со светлым тонированным фоном.
Extended сохраняет прежний Classic без изменений. Новый Classic использует
цвета символов ClassicStyleSymbols, а провода и порты — цвета из сохранённых
настроек qsiveyGlobalPresetsClassic.DXPPrf: тёмно-синие провода, бордовые контуры
и подписи портов, светло-жёлтая заливка портов.

В разноцветных пресетах контуры, графика, провода и порты используют разные
акцентные цвета, текст подобран под фон.
Например: Coastal coral, Lavender mint, Autumn ink, Sakura sky,
Mint and plum, Lagoon and raspberry, Periwinkle and teal.
Чтобы добавить свой пресет, скопируй целиком любой блок,
включая все 12 цветов, и задай уникальное имя в квадратных скобках.
Например: [Мой пресет]. Для русских названий сохраняй TXT как UTF-8 с BOM.
Порядок цветовых строк произвольный, имена полей оставляй как в примерах.
В старых собственных блоках замени PortBody на PortBorder и PortFill,
а также добавь SheetColor=#FFFFFF или другой цвет фона.

Формат цвета — #RRGGBB: #FF0000 красный, #00FF00 зелёный, #0000FF синий.
Большие и маленькие hex-буквы равнозначны. Значение из шести цифр без # тоже допустимо.
Комментарии начинаются с ; и занимают отдельную строку.

Файл перечитывается при раскрытии списка и при нажатии Apply preset.
После редактирования TXT достаточно снова открыть список; перезапуск не нужен.
При неверном hex, неизвестном или повторном поле, пропущенном цвете или повторном
имени пресета выводится предупреждение. Текущие цвета при этом не меняются.

Цвета
Body outline — контур прямоугольников и эллипсов.
Body fill — заливка только объектов Rectangle, принадлежащих компонентам.
Enable по умолчанию включён: IsSolid=True включает выбранную заливку.
Transparent — отдельный флажок, по умолчанию выключен: заливка непрозрачная.
Скрипт явно применяет выбранное состояние, в том числе отключает прозрачность,
которую могла включить предыдущая версия. Полупрозрачность применяется только
при установленном Transparent; пресеты сами её не включают.
Сами пины, их порядок, координаты, имена и настройки видимости не меняются
(цвет задаёт Pins / text).
При снятом Enable у этих Rectangle остаётся только контур. Цвет в палитре сохраняется.
Заливка отдельных Rectangle на листе, скруглённых прямоугольников и эллипсов
не меняется. Контуры по-прежнему получают цвет Body outline.
В создаваемых Defaults действует то же ограничение: только Rectangle внутри
компонента, а не отдельный шаблон Rectangle.

При включённом Enable и выключенном Transparent скрипт проверяет порядок
примитивов в текущей части и режиме отображения каждого компонента.
Если непрозрачный Rectangle идёт после пина с видимой подписью, в итоговом
Warnings появляется одно общее предупреждение: некоторые подписи пинов
могут быть закрыты заливкой. Списка пинов и компонентов нет; сообщение
не повторяется для каждого компонента или документа.
Проверяется только порядок примитивов, без расчёта пересечений и границ текста.
Поэтому предупреждение указывает на возможное, а не подтверждённое перекрытие.
При скрытых подписях или правильном порядке предупреждения нет.
Проверка только сообщает о проблеме: порядок не исправляется, прозрачность
автоматически не включается. Run продолжает обработку и сохраняет схемы.
Такая же проверка выполняется для копий компонентов при Create defaults.

Lines / polygons / arcs — графические линии, кривые, полигоны, дуги.
Parameters / designator — параметры и обозначения компонентов.
Pins / text / 20 mil arcs — выводы, их подписи, обычный текст и дуги радиуса 20 mil.
PNG images — цвет пикселей PNG, применяется только в режиме Recolor.
Wires — электрические провода; точки соединения используют этот цвет
только в режимах Manual junctions и Global color.
Port Border — цвет контура портов (PortBorder в TXT).
Port Fill — цвет заливки портов (PortFill в TXT).
Port Font — цвет текста портов. Гарнитура, размер и начертание не меняются.
Other — шины, метки цепей, символы питания, листовые символы
и входы, жгуты, текстовые рамки, директивы и остальные примитивы схемы.
Sheet Color — цвет фона самого листа (SheetColor в TXT).
Графика внутри размещённых компонентов тоже обрабатывается.

Режим Junctions
Leave unchanged — выбран по умолчанию. Скрипт не меняет существующие junction,
не создаёт новые и не меняет глобальный цвет автоматических точек.
Ранее созданные ручные точки остаются на своих местах и сохраняют цвет.
Цвет самих проводов при Run меняется во всех трёх режимах.

Manual junctions — создаёт ручные точки на выбранных листах, не меняя Preferences.
Скрипт компилирует каждый выбранный документ для получения актуальных соединений
и создаёт ручные junction в существующих автоматических точках проводов
(WireConnections с ObjectsCount >= 3). Обычные пересечения проводов без
электрического соединения не преобразуются. Узлы шин и жгутов не создаются.
Новые и существующие ручные точки получают цвет Wires.

Размер новых точек берётся из текущей настройки Wire Auto-Junctions Size.
Новые точки получают Locked=True, чтобы оставаться ручными объектами при
очистке junction в Altium. Блокировка существующих точек не меняется.
Повторный запуск не добавляет точки в уже занятые координаты.
Новые автоматические точки после редактирования схемы можно обработать
повторным запуском. В итоговом сообщении показано число созданных junction.
Если компиляция или чтение соединений не удались, создание точек на этом листе
пропускается с предупреждением; остальные цвета обрабатываются.
Для перемещения или удаления созданной точки может потребоваться снять Locked.
Если включена Manual Junctions Connection Status, Altium может показывать
дополнительный кружок глобального цвета позади ручной точки.

Global color (all schematics) — при Run задаёт глобальный Wire Auto-Junctions Color
через SchServer.Preferences.WireAutoJunctionsColor. Это влияет на автоматические
точки проводов во всех схемах Altium, включая схемы других проектов.
Новые ручные точки не создаются; уже имеющиеся ручные точки на выбранных листах
перекрашиваются в Wires. Переход в Global не удаляет созданные ранее точки.
Скрипт проверяет чтением, принят ли глобальный цвет, и сообщает результат.
Цвет автоматических узлов шин и кружка Manual Junctions Connection Status не меняется.
Возврат к Leave unchanged не восстанавливает предыдущие глобальные настройки.

Create defaults
Флажок по умолчанию выключен. Если его включить, Run создаёт в выбранной папке
со схемами два файла с общим именем, например:
  SchematicStyleDefaults-20261001-153000123.dft
  SchematicStyleDefaults-20261001-153000123.MMsdft
Первый содержит настройки mil, второй — mm. Каждый запуск создаёт новую пару.
Обе части готовятся до публикации; при ошибке неполная пара удаляется.

Источник — текущие шаблоны объектов в памяти активного Altium. Скрипт получает
отдельные копии для eImperial и eMetric через SchObjectFactoryBySettings,
добавляет их во временный лист и сохраняет через SaveSchDocument в ASCII.
Он не читает старые Defaults из Presets или AppData и не меняет исходные шаблоны.
К списку типов экспортёра Defaults установленной версии Altium добавлен Parameter Set
(всего 62 типа). Типы без шаблона пропускаются, но Wire и Parameter Set обязательны.
Копируются сами объекты, вложенные примитивы,
параметры и настройки шрифтов, а не только известные скрипту поля цвета.

К копиям применяются выбранные цвета по тем же категориям, что и к схемам,
включая Wires, раздельные Port Border / Fill / Font и Other.
После сохранения временного ASCII все оставшиеся числовые поля цвета получают Other:
Color, AreaColor, TextColor, BorderColor, SecondaryColor, TertiaryColor и другие.
Цвета, назначенные отдельным категориям, сохраняются, включая Sheet Color,
подписи пинов и Body fill у Rectangle внутри компонента.
Other также используется для цветов контейнера компонента, рамки Graphic,
Parameter Set, заливки Round Rectangle и отдельного Rectangle.
Для Junction сохраняется поведение выбранного режима, включая Leave unchanged.
У Round Rectangle цвет границы остаётся Body outline. Отсутствующие в ASCII
поля чёрного цвета для Graphic, Parameter Set и этих заливок добавляются явно.
Это дополнение действует только на создаваемые Defaults; обработка схем сохраняется.
Имена цветов, флаги, текст, координаты и остальные поля не переписываются.
Body fill / Enable и Transparent управляют заливкой и прозрачностью только
Rectangle внутри компонента. Эти флаги дополнительный проход не меняет.
Настройки PNG и Junctions тоже учитываются; ручные точки
внутри Defaults не создаются. Шрифты, размеры и прочие свойства сохраняются.
Sheet Color записывается в заголовок временного листа; загрузчик Defaults
не обязан применять фон этого листа как глобальную настройку новых схем.

При ошибке получения или сохранения текущих Defaults Run останавливается
до изменения схем, сообщает этап ошибки и не подменяет источник старым файлом.
Доступность вызовов DelphiScript и импорт результата нужно проверить в Altium.

Для применения закрой скрипт и выбери Preferences > Schematic > Defaults > Load.
Загрузи созданный .dft, оставив рядом .MMsdft с таким же базовым именем.
Затем закрой и снова открой Preferences, чтобы увидеть загруженные значения.
Это настройки новых объектов; размещённые Wire и прочие объекты меняет Run.
Загрузка DFT заменяет весь экспортированный набор Defaults, не только цвет Wire.
Глобальный цвет автоматических junctions задаётся отдельно режимом Global color.

PNG images
Leave unchanged — ничего не делать с изображениями, включая уже перекрашенные.
Recolor — взять оригиналы из Original PNG directory и подготовить цветные копии.
Return to original image — взять из той же папки оригинальные PNG и скопировать
их без изменения байтов; затем заново загрузить изображения в схемах.
Выбранный цвет PNG images в режиме возврата не используется.

И цветные, и исходные копии сохраняются в Images внутри папки схем.
Ссылки на копии записываются как Images\имя_файла.png относительно SchDoc.
В Recolor имя копии: исходное_имя_HEXxxxxxx.png, где xxxxxx — RGB в HEX.
Например, TiR.png для красного превращается в Images\TiR_HEXFF0000.png.
В Return to original image сохраняется исходное имя, например Images\TiR.png.
Это действует для Recolor и Return to original image. Состояние Embedded сохраняется.
Схемы можно переносить вместе с подпапкой Images.
Original PNG directory по умолчанию указывает на Images в каталоге библиотек.
Папка оригиналов должна отличаться от папки копий. Имена исходных PNG должны
совпадать с исходными именами картинок в схемах. Скрипт распознаёт собственные
суффикс _HEXxxxxxx, а также старые .__lsc_v2_ и .__lsc_original_v1_, поэтому можно повторять цикл
Recolor > Return to original image > Recolor с любыми выбранными цветами.
Отсутствующий оригинал оставляет картинку прежней и попадает в предупреждения.
Другие форматы изображений не меняются. Встроенность изображения сохраняется.

RecolorImages.ps1 должен оставаться рядом с PAS. Он запускается автоматически.
Цветная копия сохраняет альфа-канал, исходная копия совпадает с оригиналом байт
в байт. При каждом запуске копия обновляется из текущего оригинала, в том числе
когда цвет и имя копии остались прежними. Хеш в имя файла не добавляется.
Ранее созданные копии остаются в Images, чтобы не повредить ссылки других схем.

Справка Schematic / Defaults:
https://www.altium.com/documentation/altium-designer/preferences/schematic

Открытые листы остаются открытыми. Листы с несохранёнными правками пропускаются:
сначала сохрани их, затем повтори Run. Результат сообщает число сохранённых
схем и перекрашенных изображений; неполная обработка сопровождается предупреждением.

Проверка внутри Altium выполняется пользователем.
