LibraryGraphicPaths v1.0.2

Отдельный скрипт для Altium Designer. Обрабатывает все .SchLib непосредственно
в выбранной папке; подпапки не сканируются.

Запуск
1. Открой LibraryGraphicPaths.PrjScr в Altium.
2. Запусти RunLibraryGraphicPaths.
3. Выбери папку с библиотеками, настрой галочку Embedded и нажми Run.
   По умолчанию выбрана CustomStyleSymbols из каталога библиотек Altium.
   Embedded по умолчанию включён. Сними галочку для внешних изображений.
4. Результаты по каждой библиотеке появятся в журнале окна.

Что меняется
Во всех компонентах ищутся Graphic / Image (eImage), включая примитивы
активного компонента, все части и варианты отображения.
Путь каждого изображения становится ..\Images\имя_файла.
Embedded устанавливается согласно галочке: включён или выключен.
Например: D:\qsivey\Altium\Libraries\Images\TiR.png -> ..\Images\TiR.png.
Имя и расширение сохраняются, в том числе для изображений не в формате PNG.
Уже относительные пути тоже приводятся к указанному виду.
Картинка с правильным путём и выбранным состоянием Embedded не изменяется.

Изображения
Скрипт меняет только FileName и EmbedImage, без принудительной перезагрузки
пикселей и без обращения к координатам, рамке или повороту Graphic.
При включённой галочке уже встроенные пиксели сохраняются, даже если исходного
файла на диске больше нет. Для внешнего Graphic встраивается изображение,
которое Altium загрузил из текущей ссылки при открытии библиотеки.
Если текущий источник внешнего Graphic отсутствует, библиотека пропускается.
В этом случае сначала запусти скрипт с выключенным Embedded, затем переоткрой
библиотеку, чтобы Altium загрузил файл из Images, и запусти со включённым Embedded.
При выключенной галочке изображение сохраняется как внешнее, Embedded=False,
со ссылкой ..\Images\имя_файла относительно библиотеки.
Файл по этому пути должен существовать; старого абсолютного источника недостаточно.
В открытом редакторе может оставаться загруженная ранее картинка. Переоткрытие
библиотеки загружает внешний файл по новой ссылке.
Если нужный источник отсутствует или имя пустое, вся библиотека пропускается
до внесения изменений; журнал показывает библиотеку и компонент.
Скрипт не перекрашивает картинки и не копирует внешние файлы в Images.
Относительный путь указывает на Images рядом с папкой библиотек. Встроенные
изображения сохраняются внутри SchLib и не требуют внешнего файла для показа.

Сохранение
Перед изменениями создаётся копия исходной библиотеки в
<выбранная папка>\_GraphicPathsBackup\<дата-время>\.
Библиотеки без изменений не пересохраняются. Повторный запуск не создаёт
новых копий для уже обработанных файлов.
Открытые библиотеки с несохранёнными правками пропускаются.
При ошибке во время изменения библиотека не сохраняется и остаётся открытой;
перед повторным запуском закрой её без сохранения и открой с диска.
При ошибке сохранения исходная копия остаётся в папке резервных копий.
Итоговый Report.txt сохраняется рядом с резервными копиями.

Graphic соответствует ISch_Image; использованы FileName и EmbedImage:
https://www.altium.com/documentation/altium-dxp-developer/schematic-api-design-objects-interfaces-reference
