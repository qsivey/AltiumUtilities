LibraryStyleChanger v1.4.6

Открой LibraryStyleChanger.PrjScr и запусти RunLibraryStyleChanger.
По умолчанию выбрана папка CustomStyleSymbols внутри каталога библиотек Altium.
Выбери нужные SchLib, настрой цвета и нажми Run. Скрипт сохраняет выбранные
библиотеки на месте; подкаталоги не сканируются.

Пресеты
Внизу группы цветов выбери пресет в списке и нажми Apply preset.
Пресет задаёт все шесть цветов: Body outline, Body fill, Lines / arcs,
Parameters / designator, Pins / text / 20 mil arcs и PNG images.
К библиотекам цвета применяются кнопкой Run.
Флажки Enable, Transparent и Recolor PNG pixels сохраняют своё состояние.

Используется общий со скриптом для схем файл Libraries\StylePresets.txt.
Скрипт ищет его по пути ..\..\..\Libraries\StylePresets.txt от своей папки.
Все 37 имеющихся пресетов доступны и для библиотек. Значения Wires, PortBorder,
PortFill, PortFont, Other и SheetColor проверяются при чтении, но не применяются.
Classic и Extended задают одинаковые цвета библиотек: их отличия относятся к схемам.

Чтобы добавить пресет, скопируй целиком любой блок [Имя], включая все 12 полей,
задай уникальное имя и измени цвета. Поля BodyOutline, BodyFill, Graphics,
Parameters, PinText и Images соответствуют шести цветам библиотеки.
Формат цветов — #RRGGBB, например #FF0000 для красного. Регистр hex-букв
не важен, шесть цифр без # тоже допустимы. Комментарии начинаются с ;
и занимают отдельную строку. Для русских названий сохраняй TXT как UTF-8 с BOM.

Файл перечитывается при раскрытии списка и нажатии Apply preset.
При ошибке в файле выводится предупреждение, текущие цвета сохраняются.
Если файл недоступен, цвета по-прежнему можно выбрать вручную.

Body fill
Rectangle и Polygon внутри компонентов используют одинаковые настройки:
Body outline задаёт контур, Body fill — заливку.
Enable по умолчанию включён: прямоугольники и полигоны получают выбранную заливку.
При снятом Enable остаются только контуры, цвет в палитре сохраняется.
Transparent по умолчанию выключен: заливка непрозрачная. Прозрачность
включается только этой галочкой и никогда не применяется автоматически.
Заливка, прозрачность и признак IsSolid эллипсов и скруглённых прямоугольников
сохраняются; их контуры получают цвет Body outline.
Кнопка One color for all six accents меняет только цвета, не состояния галочек.
Обрабатываются как сохранённые примитивы компонентов, так и примитивы активного
компонента, которые Altium временно хранит в контейнере редактора библиотеки.
Поэтому настройки применяются и к первому (активному) компоненту библиотеки.
После обработки обновляется отображение и отмечается необходимость сохранения.

Предупреждение о порядке примитивов
При включённом Enable и выключенном Transparent скрипт проверяет все части
и варианты отображения каждого библиотечного компонента.
Если непрозрачный Rectangle или Polygon идёт после пина с видимой подписью, в итоговом
Warnings появляется предупреждение о возможном перекрытии подписей с именем
файла библиотеки .SchLib. Для каждой затронутой библиотеки оно выводится один раз.
Список пинов и компонентов не выводится. Проверяется только порядок записей,
без расчёта границ текста или пересечений. Это предупреждение о возможном,
а не подтверждённом перекрытии. Оно не прерывает обработку библиотек.
Скрипт не переставляет примитивы и не меняет выбранную часть или вариант
отображения компонента. Пины сохраняют координаты, имена и настройки видимости.

Остальные настройки
Сохраняются шесть цветов, общая кнопка цвета и флажок Recolor PNG pixels.
При включённой перекраске оригиналы PNG берутся из соседней папки Images,
а цветные копии сохраняются в Images внутри выбранной папки библиотек.
Ссылки на эти копии записываются как Images\имя_файла.png относительно SchLib.
Имя цветной копии: исходное_имя_HEXxxxxxx.png, где xxxxxx — RGB в HEX.
Например, TiR.png для красного превращается в Images\TiR_HEXFF0000.png.
При повторном запуске копия того же цвета обновляется из текущего оригинала.
Для поиска оригинала распознаются новый суффикс _HEXxxxxxx и старые суффиксы
.__lsc_v2_ / .__lsc_original_v1_. Старые файлы автоматически не удаляются.
Состояние Embedded сохраняется. Папку библиотеки можно переносить вместе с Images.
При выключенной перекраске изображения остаются без изменений.
RecolorImages.ps1 должен находиться рядом с LibraryStyleChanger.pas.
